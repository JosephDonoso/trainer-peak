# Instalar desde GitHub Pages en Android

1. Abre en Chrome la dirección HTTPS que aparece en Settings → Pages de tu repositorio.
2. Espera en Datos a que los archivos estén preparados para abrir sin conexión.
3. Usa Instalar app o Chrome → Añadir a pantalla de inicio / Instalar app.
4. Abre desde el icono una vez conectado, después prueba en modo avión.

No requiere USB, un ordenador encendido, backend ni cuenta en la app. Cada teléfono conserva sus propios datos. No sincroniza con familiares.

Si vienes de localhost, exporta la copia JSON desde la versión anterior e impórtala en esta. No borres la versión anterior hasta comprobar la importación. Cambiar el dominio o ruta de publicación también requiere migrar los datos.

Para actualizar, usa Datos → Buscar actualizaciones con internet y después cierra y abre la app. El almacenamiento de entrenamientos no se borra al actualizar los archivos. Conserva copias periódicas por si se borran los datos del navegador.

La instalación real en tu teléfono queda pendiente de comprobar. Los avisos de descanso con la pantalla bloqueada dependen del navegador y del sistema operativo.
